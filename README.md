# Global Weather Hub 🌍🌤️

A beautiful, sleek, and highly responsive single-page Weather Application built entirely using HTML5, Tailwind CSS, FontAwesome, and vanilla JavaScript. 

The application provides instant, live weather tracking for the most popular places on Earth, powered directly by the free, fast, and high-precision **Open-Meteo API** (no registration or API key required!).

## ✨ Features

- **Top 10 Global Destinations:** Immediate dashboard view of current weather conditions in Tokyo, New York, Paris, London, Sydney, Cairo, Rio de Janeiro, Dubai, Cape Town, and Mumbai.
- **Detailed Forecast Panel:** Click on any city to pull up a full metric report including humidity, wind speed, precipitation, and time-of-day indicators.
- **Global Search:** Find any city on earth using the integrated real-time Geocoding search autocomplete box.
- **Dual Units:** Fast Celsius/Fahrenheit conversion toggle.
- **Dynamic Styling:** Stunning modern dark glassmorphism card designs and responsive gradients that change based on weather conditions.
- **Fully Standalone:** Zero dependencies to install, no build step required—just double-click `index.html` and go!

## 🚀 Quick Start

Simply open the `index.html` file in any modern web browser:

```bash
# On Linux/macOS
open index.html

# On Windows
start index.html
```

## 🛠️ Built With

- **HTML5 & CSS3** for clean semantic layouts
- **Tailwind CSS (via CDN)** for design system and utility classes
- **FontAwesome (via CDN)** for high-quality weather icons
- **Vanilla JavaScript** (ES6 Async/Await, Fetch API) for fast, keyless API integrations
- **Open-Meteo API** for live global geocoding and weather parameters
